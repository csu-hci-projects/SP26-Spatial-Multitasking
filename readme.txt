Project Summary:
This project compares two VR workspace layouts for a multitasking spaceport inspection task. Participants completed the same workflow in a gravity-based desk condition and a zero-gravity condition. We measured completion time, task timing, wrong code submissions, and decision accuracy.

Instructions for Running the App:
1. Open the Unity project in Unity.
2. Open the Gravity scene or Zero-G scene.
3. Make sure the Meta Quest headset is connected and configured.
4. Press Play or build to the headset.
5. Follow the in-game task sequence: keycard, radio, keypad, scanner, approve/deny decision.

Notes:
The project includes two experimental conditions: Gravity and Zero-G. The same workflow is used in both conditions so performance can be compared. The ExperimentLogger script records participant and condition data to CSV files.
